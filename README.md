A simple template for a [landing page](https://en.wikipedia.org/wiki/Landing_page).

This project was created during my journey with [The Odin Project (TOP)](https://theodinproject.com), as a practice on [CSS foundations](https://www.theodinproject.com/paths/foundations/courses/foundations#css-foundations) and [CSS flexible box (flexbox)](https://www.theodinproject.com/paths/foundations/courses/foundations#flexbox). It also helped get me used to using the internet to solve novel problems or problems I have encountered before but do not remember the solution for.

## Viewing the page

You can [view the page on GitHub Pages](https://alikamel-dev.github.io/landing-page).

> [!IMPORTANT]
> About supported devices and browsers:
>
> - The page is designed to be played in a 1920 × 1080 screen/window resolution. The website is not completely responsive, and is likely to produce worse visual results on smaller screen sizes, especially mobile phone screens.
> - The page is primarily developed for [Google Chrome](https://google.com/chrome). It should function properly in fairly new versions of major web browsers, though minor visual differences may arise.

## Design

The design of this project aims to closely replicate the original design provided by The Odin Project, which can be found in a [dedicated directory for design files in the main branch of the repository](https://github.com/alikamel-dev/landing-page/tree/main/design).

The aforementioned directory contains two PNG image files:

1. [An image of the full design of the page, `design.png`](https://github.com/alikamel-dev/landing-page/tree/main/design/design.png)
2. [An image containing the colors and font styles used for the page, `colors-and-font-styles.png`](https://github.com/alikamel-dev/landing-page/tree/main/design/colors-and-font-styles.png)

> [!NOTE]
> The term _hero text_, used in the image containing colors and font styles, refers to the statement that appears at the top of a webpage.

Obviously, my implementation of the design may differ from the original design in some aspects, especially layout measurements, since The Odin Project does not provide details on them. Though not required by The Odin Project, I tried to get close values to these measurements, using virtual ruler software and by trying out different keyword values affecting spacing (such as the different values for `justify-content` in flex containers) and seeing how similar the produced result is to its counterpart in the original design.

The spacing between the horizontally-stacked items (such as the left and right parts of the header and hero section) will most likely differ from the design due to the difference in the screen resolution and/or the level of zoom between your display and the design image.
